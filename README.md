# B站抽奖助手

一个帮助B站用户自动参与抽奖活动的浏览器扩展。（仅限制使用B站官方抽奖工具的抽奖活动）

## 功能特点

- 自动查找并点击抽奖链接
- 自动关注UP主并转发抽奖动态
- 合并 `www.bilibili.com/opus/<id>` 与 `t.bilibili.com/<id>`，按动态 ID 去重
- 自动滚动采集懒加载链接，新增链接实时追加到处理队列
- 停止时取消后续开页、滚动和待执行点击；保留当前动态页供手动查看
- 遇到验证码暂停，完成验证后可继续当前队列
- 区分已处理、已点击与跳过的数量；加载和互动超时自动跳过
- 后台服务暂停后恢复队列状态，防止重复消息推进任务或关闭其他标签页

## 安装方法

1. 下载本仓库代码
2. 打开 Chrome 120 或更新版本，进入扩展管理页面 (chrome://extensions/)
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择本项目文件夹

## 使用说明

1. 访问B站抽奖合集页面（类似https://www.bilibili.com/opus/1055344069620793408 ）
2. 页面会自动显示悬浮控制面板；扩展图标可以隐藏或重新显示面板
3. 点击右下角"开始"按钮开始自动参与抽奖
4. 随时可通过"停止"按钮中断操作
5. 出现验证码时，在保留的动态页手动完成验证，再回来源页点击“继续”；“停止”会结束该队列

队列清空后会再等待 6 秒接收新链接，然后结束。采集上限为 10,000 条动态。关闭来源页会停止任务；手动关闭当前动态页会跳过该条。一次只能运行一个队列。

“已点击”表示已对参与按钮执行点击，不表示 B 站已确认参与成功，请以网站提示为准。无法访问的跨域弹窗会跳过，验证码须手动处理。

队列保存在浏览器会话中，可在后台服务休眠后恢复；浏览器重启、扩展重新加载、更新或禁用后，队列会清空。面板位置另行保存，拖动时限制在可见窗口内。

## 本地验证

安装 Node.js 18 或更新版本，无需安装第三方依赖：

```sh
npm run check
npm test
```

回归测试使用模拟的 Chrome API、DOM 与时钟，覆盖队列追加、停止、验证码暂停与继续、重复消息、超时、关页及后台恢复；不会实际关注、转发或参与抽奖。真实页面的选择器与参与结果仍需在浏览器中确认。

扩展使用 `tabs`、`storage` 与 `alarms` 权限管理动态页、保存状态及恢复超时任务，移除了未使用的 `scripting` 权限。
